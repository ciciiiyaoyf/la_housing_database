# Data exports and variable definitions

Contains generated shareable data tables and query selections. Most data files
are local only; [variable_dictionary.csv](variable_dictionary.csv) is the published
full variable-definition export.

The query tool writes an accompanying `<name>.variables.csv` for a wide-table
export, mapping columns and scenario rows to IDs, units, temporal types, and
methods. Keep it with the data. The browser saves downloads to the browser's
chosen download folder, not necessarily here. Existing query output files are
not overwritten. Licensed HUD-USPS detail is excluded from ordinary exports.
