# Immutable public-source archives

Original provider payloads, grouped by provider and source. A source may have many
retrieved vintages. Downloads preserve source filename, URL/request, source vintage,
retrieval timestamp, geography, size, and checksum in the local raw manifest.

Do not edit, overwrite, rename, or delete archived payloads. Cleaners choose inputs
through provenance records; a folder name alone does not establish active use.
The national Redfin ZIP file stays raw-only. Payloads are not shipped with Git;
provider/vintage folders use this common guide.
