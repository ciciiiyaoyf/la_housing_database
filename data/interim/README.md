# Intermediate transformations

Reusable local results between acquisition and analytical outputs, such as the
Los Angeles subset and long-form observations built from national Redfin ZIP data.

These are derived files, not original provider payloads. Their source lineage and
transformation definitions must remain recoverable. Other pipeline stages may
consume them, so absence from Git does not mean they can be deleted safely.
Rebuild them through the pipeline rather than editing observations manually.
