# Licensed HUD-USPS data

Local raw, staging, and active outputs for the official quarterly HUD-USPS
residential-address vacancy proxy. Detailed data and modeled derivatives remain
restricted; only permitted metadata and methodology belong in Git.

The raw archive is immutable. County aggregates require complete tract components;
modeled postal-ZIP rows represent LA County portions of ZIPs, not whole ZIPs or
Census ZCTAs. Vacancy is all-residential administrative vacancy, not renter-only
listing inventory. Use the source methodology and active source manifest before
rebuilding or interpreting this layer.
