# Restricted local data

Access-controlled raw inputs and detailed derived data. They are excluded from
Git and ordinary public CSV exports; documenting a folder does not grant access
to its contents or permission to redistribute them.

[hud_usps/](hud_usps/README.md) holds the licensed HUD-USPS workflow. Other retained
local subfolders do not establish an active source contract; consult configuration
and provenance before using them. Preserve raw vintages and supporting files.
Do not copy this tree into a shared database or download bundle.
