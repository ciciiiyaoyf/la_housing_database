# Retired non-seasonally adjusted ZORI archive

Preserves earlier NSA Zillow rent vintages and their [archive manifest](archive_manifest.csv).
These files are excluded from active ingestion, clean tables, facts, and panels.

Do not delete, edit, or move archived payloads. They remain historical provenance,
not an alternative active rent source. The current pipeline uses only smoothed,
seasonally adjusted ZORI for all homes plus multifamily.
