# Published reference workbooks

[reference_workbooks/](reference_workbooks/README.md) contains dated Excel
inventories and finance comparisons for readers. These are reference documents,
not the local analytical database or freshly generated CSV exports.

Use the current metadata inventories for the maintained build and the main data
guide for consolidated findings. The former standalone metro progress report is
now covered there; its authoring/QA tools are preserved under `scripts/report_authoring/`.
Generated pipeline delivery and QA files belong in `output/` (singular).
