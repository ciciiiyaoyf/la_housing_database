# Historical build evidence

Contains superseded machine-readable records retained for audit and reproducibility.

`hud_usps_official_rebuild_summary_20260803.csv` records the August 3, 2026 build;
it does not describe current coverage. Current inventories live in the parent
metadata folder. Historical evidence is preserved rather than rewritten to match
later data or copied into another status report.
